# One capstone, three front doors — worked example papers

`index.html` is a single self-contained page holding **three complete write-ups of the same
capstone project**, side by side with a toggle (or one at a time):

| Door | Written for | Purpose |
|---|---|---|
| 1 | ML engineers and technical reviewers | credibility — work that survives hard questions |
| 2 | interviews, HR and employers | proof of ML knowledge when applying for jobs |
| 3 | the SEO community | practical, shareable insight |

The point of the artifact is the rule printed in its header: **the evidence, the numbers, the
limitations and the methods never change between the three versions.** Only the framing, the
order, the lead visual, the tone and the page design adapt to the reader. Same evidence,
chosen door.

Use it as a structure reference for your own deployed paper (Week 7 → Week 8). It is a worked
example, not a template to submit: the demo, code and report buttons are inert placeholders,
and the numbers belong to one reference project, not to yours.

Every figure and number on the page is generated from that project's committed metric
receipts, so the three versions cannot drift apart. Claims stay observed, measured and
decision-support: predictive, not causal.

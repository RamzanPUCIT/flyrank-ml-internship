# Frame It as Cases: Work That Speaks for Itself

**Voice card:** plain words · numbers always next to a baseline · say where the evidence stops · short sentences.

## Case 1 — Which pages should an editor refresh first? (FlyRank ML capstone)
- **Problem:** content teams have hundreds of pages and time to refresh only a few each week.
- **What I did:** built a per-site review queue for 18,000+ anonymized pages from earlier-window signals; compared a
  3-signal rule with Logistic Regression and Random Forest on sites the models never saw.
- **What came of it:** the rule's top 50 were right ~81% of the time vs ~63% random; models did not beat it.
  Live paper: https://ramzanpucit.github.io/flyrank-ml-internship/

## Case 2 — Urdu receipt & invoice templates (next case, in progress)
- **Problem:** a family grocery store used inconsistent handwritten receipts.
- **What I did:** designing print-ready A5 Urdu templates with AI help (HTML/SVG → PDF).
- **What came of it:** to be added after first print run (reminder set monthly).

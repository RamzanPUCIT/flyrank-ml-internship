# Three Roads: Choose Your Stack with AI

**Chosen stack: plain HTML/CSS on GitHub Pages.**

| Road | Pros | Cons |
|---|---|---|
| **GitHub Pages + static HTML/CSS** (chosen) | free, no new account (repo already exists), HTTPS, version history, my capstone paper already runs there | no CMS, edits are code |
| Next.js on Vercel | components, fast, nice previews | build tooling and a framework to learn while I am busy with M.Phil research |
| Notion / Framer site builder | fastest to edit, no code | paid custom domain, harder to show technical skill, lock-in |

**Why:** my audience is a technical hiring manager and my main proof is a research paper plus notebooks. A static
site on GitHub keeps everything in one public, versioned place I already maintain, costs nothing, and is quick to
update. I can move to Next.js later if I need interactivity.
